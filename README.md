# Synthetic Data Engineering & Privacy Platform

**V0.3 — Execution Platform**

A modular synthetic data engineering and privacy evaluation platform designed
to generate useful synthetic datasets while evaluating schema integrity,
statistical quality, and privacy risk.

V0.3 adds an API-driven job execution layer around the V0.2 synthetic-data
engine.

API
The V0.3 API is available under:
/api/v1/

Health
GET /api/v1/health

Returns the service health status.
Version
GET /api/v1/version

Returns the platform version.
Create Job
POST /api/v1/jobs

Creates and queues a synthetic-data generation job.
Request:
{
  "input_file": "data/input/dev_dataset.csv",
  "row_count": 1000
}

Get Job Status
GET /api/v1/jobs/{job_id}

Returns the current job state and execution details.
List Artifacts
GET /api/v1/jobs/{job_id}/artifacts

Lists artifacts generated by a completed job.
Download Artifact
GET /api/v1/jobs/{job_id}/artifacts/{artifact_name}

Retrieves a generated artifact such as:
synthetic_data.csv
report.json

Docker
V0.3 can be run as a Dockerized FastAPI service.
Build:
docker build -t synthetic-data-platform:v0.3 .

Run:
docker run -d `
  --name sdp-v03 `
  -p 8000:8000 `
  -v sdp_v03_data:/app/data/output/jobs `
  synthetic-data-platform:v0.3

Health check:
GET http://localhost:8000/api/v1/health

The named Docker volume keeps job metadata and generated artifacts
persistent across container recreation.

V0.3 Scope
V0.3 intentionally uses a simple local execution architecture.
The following are outside the V0.3 scope:
- Kubernetes
- Kafka
- Redis
- RabbitMQ
- Production PostgreSQL
- Authentication
- RBAC
- Billing
- Multi-tenancy
- Enterprise SSO
- Cloud deployment
- Distributed worker orchestration
- Horizontal worker scaling
- Object-storage integration
- Relational or multi-table synthesis
The job queue is in-memory, the worker runs within the API process, SQLite
stores job metadata, and generated artifacts use local filesystem storage.
Privacy Notice
A successful privacy evaluation is an evaluation result, not a complete
privacy, legal, or regulatory certification.
The platform does not claim that a PASS result protects against every
possible re-identification, inference, or privacy attack.
